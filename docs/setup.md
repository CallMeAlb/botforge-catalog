BotForge Business Card — инструкция по запуску
Эта инструкция поможет запустить Telegram-бота-визитку и настроить его под себя.


⸻


1. Что понадобится
Для запуска вам понадобятся:
компьютер на Windows;
установленный Python 3.12;
Telegram;
Telegram-аккаунт;
токен вашего бота.


⸻


2. Установка Python
Скачайте и установите Python 3.12.
После установки откройте PowerShell и выполните:
python --version
Если команда python не работает, попробуйте:
py --version
Должна отображаться версия Python 3.12.x.


⸻


3. Открытие проекта
Распакуйте проект в удобную папку.
Откройте эту папку в VS Code.
В VS Code откройте:
Terminal → New Terminal


⸻


4. Создание виртуального окружения
В терминале выполните:
py -m venv venv
После этого активируйте окружение:
.\venv\Scripts\Activate.ps1
Если всё прошло успешно, в начале строки терминала появится:
(venv)


⸻


5. Установка зависимостей
В активированном виртуальном окружении выполните:
pip install -r requirements.txt
Дождитесь завершения установки.


⸻


6. Создание Telegram-бота
Откройте Telegram.
Найдите:
@BotFather
Нажмите Start и отправьте:
/newbot
BotFather попросит указать:
Название бота.
Username бота.
После создания BotFather выдаст токен.
Он выглядит примерно так:
123456789:ABCDEFxxxxxxxxxxxxxxxx
⚠️ Никому не передавайте этот токен.


⸻


7. Добавление токена
В корневой папке проекта создайте файл:
.env
Внутри напишите:
BOT_TOKEN=ВАШ_ТОКЕН
Например:
BOT_TOKEN=123456789:ABCDEFxxxxxxxx
Сохраните файл.


⸻


8. Настройка информации
Откройте:
data/profile.py
Это главный файл настройки содержимого бота.
Вам не нужно разбираться во всём программном коде.
В большинстве случаев достаточно изменить информацию внутри PROFILE.


⸻


Имя
"name": "Иван Петров",
Замените на своё имя.
Например:
"name": "Алексей Смирнов",


⸻


Профессия
"profession": "Видеограф",
Например:
"profession": "Фотограф",


⸻


Город
"city": "Пермь",


⸻


Короткое описание
"intro": "Создаю визуальный контент, который помогает бизнесу и личным брендам выглядеть профессионально.",
Этот текст отображается в главном сообщении бота.


⸻


Раздел «Обо мне»
"about": (
    "Занимаюсь видеосъемкой, монтажом и созданием "
    "контента для бизнеса и блогеров."
),
Напишите здесь более подробную информацию о себе или своей компании.


⸻


9. Настройка услуг
Услуги находятся здесь:
"services": [
    "🎥 Видеосъемка",
    "✂️ Монтаж видео",
    "📱 Контент для социальных сетей",
    "📢 Рекламные ролики",
],
Можно изменить названия и количество услуг.
Например:
"services": [
    "📸 Фотосъемка",
    "🎬 Видеосъемка",
    "🎨 Обработка фотографий",
],


⸻


10. Настройка контактов
Контакты находятся здесь:
"contacts": {
    "phone": "+7 900 000-00-00",
    "telegram": "@username",
},
Замените телефон и Telegram на свои.


⸻


11. Настройка ссылок
Ссылки находятся здесь:
"links": {
    "telegram": "https://t.me/username",
    "vk": "",
    "website": "",
    "portfolio": "",
},
Если ссылка нужна — укажите её.
Если ссылка не нужна — оставьте пустую строку:
""
Например:
"links": {
    "telegram": "https://t.me/myname",
    "vk": "https://vk.com/myname",
    "website": "",
    "portfolio": "https://example.com",
},


⸻


12. Запуск бота
После завершения настройки убедитесь, что виртуальное окружение активно:
(venv)
Затем запустите:
python main.py
Если команда python не работает:
py main.py
Если всё работает, появится:
BotForge Catalog запущен!
Не закрывайте терминал — пока он открыт, бот работает.


⸻


13. Проверка
Откройте своего бота в Telegram.
Отправьте:
/start
Проверьте все разделы:
👤 Обо мне
💰 Услуги
📞 Контакты
🎥 Портфолио
ссылки
⬅️ Назад
Если всё отображается правильно — бот настроен.


⸻


14. Как остановить бота
В терминале нажмите:
Ctrl + C
Бот остановится.


⸻


15. Как снова запустить бота
Откройте терминал в папке проекта.
Активируйте виртуальное окружение:
.\venv\Scripts\Activate.ps1
Затем:
python main.py


⸻


⚠️ Важная информация
Не передавайте токен бота
Файл:
.env
содержит секретный токен.
Никому его не отправляйте и не публикуйте.


⸻


Не удаляйте 
.gitignore
Он нужен для того, чтобы секретные и служебные файлы не попадали в Git.


⸻


Готово
После выполнения этих шагов у вас будет полностью настроенная Telegram-визитка.
Теперь вы можете отправить пользователям ссылку на своего бота и использовать его как цифровую визитку.
