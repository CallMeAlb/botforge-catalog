BotForge — Telegram Business Card
Универсальный шаблон Telegram-бота-визитки для специалистов, фрилансеров, предпринимателей и небольших компаний.
Бот помогает представить себя, показать услуги, контакты и ссылки на внешние площадки.


⸻


✨ Возможности
👋 Приветственное сообщение
👤 Раздел «Обо мне»
💰 Раздел «Услуги»
📞 Раздел «Контакты»
🔗 Динамические кнопки со ссылками
🎥 Раздел «Портфолио»
⬅️ Навигация без засорения чата
⚙️ Настройка через один файл profile.py


⸻


🚀 Установка
1. Установите Python
Проект рассчитан на Python 3.12.
Проверить установленную версию:
python --version
Если команда python не работает:
py --version


⸻


2. Скачайте проект
Склонируйте репозиторий:
git clone https://github.com/YOUR_USERNAME/Botforge-catalog.git
Перейдите в папку проекта:
cd Botforge-catalog


⸻


3. Создайте виртуальное окружение
py -m venv venv
Активируйте его.
Windows PowerShell
.\venv\Scripts\Activate.ps1
Windows CMD
venv\Scripts\activate.bat
После активации в начале строки терминала должно появиться:
(venv)


⸻


4. Установите зависимости
pip install -r requirements.txt


⸻


🤖 Создание Telegram-бота
Для работы проекта нужен Telegram-бот и его токен.
Откройте Telegram.
Найдите официального бота @BotFather.
Отправьте команду /newbot.
Укажите название бота.
Укажите username бота.
Скопируйте полученный токен.
⚠️ Никому не передавайте токен вашего бота.


⸻


🔐 Настройка токена
В корневой папке проекта создайте файл:
.env
Внутри файла укажите:
BOT_TOKEN=ВАШ_ТОКЕН
Например:
BOT_TOKEN=123456789:ABCDEF...
⚠️ Не публикуйте файл .env и не передавайте его другим людям.


⸻


✏️ Настройка бота
Основные настройки находятся в файле:
data/profile.py
Откройте его и измените информацию на свою:
PROFILE = {
    "name": "Иван Петров",
    "profession": "Видеограф",
    "city": "Пермь",

    "intro": "Создаю визуальный контент, который помогает бизнесу и личным брендам выглядеть профессионально.",

    "about": (
        "Занимаюсь видеосъемкой, монтажом и созданием "
        "контента для бизнеса и блогеров."
    ),

    "services": [
        "🎥 Видеосъемка",
        "✂️ Монтаж видео",
        "📱 Контент для социальных сетей",
        "📢 Рекламные ролики",
    ],

    "contacts": {
        "phone": "+7 900 000-00-00",
        "telegram": "@username",
    },

    "links": {
        "telegram": "https://t.me/username",
        "vk": "",
        "website": "",
        "portfolio": "",
    },
}
Что нужно изменить
Поле
Назначение
name
Ваше имя
profession
Ваша профессия
city
Ваш город
intro
Короткое описание в приветствии
about
Подробная информация о вас
services
Список ваших услуг
contacts
Контактные данные
links
Ссылки на ваши площадки


⸻


🔗 Добавление ссылок
Если ссылка нужна, укажите её:
"telegram": "https://t.me/username"
Если ссылка не нужна, оставьте пустую строку:
"vk": ""
Пустые ссылки автоматически не отображаются в боте.


⸻


▶️ Запуск бота
После настройки запустите:
python main.py
Если команда python не работает:
py main.py
После успешного запуска в терминале появится:
BotForge Catalog запущен!
После этого откройте своего бота в Telegram и отправьте:
/start

🛠 Возможные проблемы
Бот не отвечает
Проверьте:
запущен ли main.py;
правильно ли указан BOT_TOKEN;
подключен ли компьютер к интернету;
доступен ли Telegram API.


⸻


ModuleNotFoundError
Убедитесь, что виртуальное окружение активировано.
В начале строки терминала должно быть:
(venv)
После этого выполните:
pip install -r requirements.txt


⸻


BUTTON_URL_INVALID
Проверьте ссылки в:
data/profile.py
URL должен начинаться с:
https://
Например:
https://t.me/username


⸻


getaddrinfo failed
или 
TelegramNetworkError
Это означает, что компьютер не может подключиться к Telegram API.
Проверьте:
интернет-соединение;
VPN, если он необходим для доступа к Telegram;
работу api.telegram.org.
Обычно проблема связана с сетью, DNS или VPN, а не с кодом бота.
